Recursive deletes (rm -r, rm -rf, find -delete, rimraf) must name a literal path (rm -rf -- /tmp/tmp.Ab12), or keep the mktemp variable and the delete in the same command under your own variable name such as d - never TMP, TMPDIR, TEMP, HOME, PWD or another shell or runtime variable (d=$(mktemp -d); ...; rm -rf -- "$d"). Never delete a $VAR set in an earlier command; the fleet delete guard blocks it, and a delete-guard block is final: do not retry it, reword it, or work around it.
