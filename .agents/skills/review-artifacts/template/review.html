03

Compare aligned options

Give every option the same anatomy and make the recommendation, cost, risk, and reversibility equally visible.

Option A

Keep routing implicit

Use current intake judgment with no operator-visible model.

  • Lowest implementation cost
  • Hardest decisions to audit
  • Immediately reversible
Option B - Recommended

Visible ordered rules

Expose the same routing logic as a small ordered rule set.

  • Moderate implementation cost
  • Clear precedence and ownership
  • Rules can be disabled safely
Option C

Automatic reassignment

Continuously move tasks when ownership evidence changes.

  • Highest implementation cost
  • Introduces surprising movement
  • Difficult to reverse in flight
Recommendation
Choose visible ordered rules. It makes current judgment inspectable without expanding scope into autonomous reassignment.
Primary risk
Rule order can become hidden policy. Mitigate it with visible precedence, a default route, and a plain-language explanation for every match.
