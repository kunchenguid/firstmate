# Links and cross-references

Lookup owner: [Cross-references and linking](https://developers.google.com/style/cross-references).

## Descriptive link text

Link text must make sense when read alone.

Recommended: `For quota limits, see [Quotas and limits](https://example.com/quotas).`

Not recommended: `For quota limits, click [here](https://example.com/quotas).`

Not recommended: `See https://example.com/quotas.`

## Introducing links

- Prefer **see** to introduce links and in-page cross-references when it reads naturally.
- Put punctuation outside link text unless the punctuation belongs to the linked title itself.

## Unexpected behavior

Tell readers when a link:

- Downloads a file
- Opens a new tab or window
- Jumps to an in-page anchor they might not expect

## Adjacent links

Separate consecutive links when practical so screen readers and magnifiers can distinguish targets.

## UI paths and menu sequences

When documenting menu paths with `>`, ensure assistive technologies can interpret the separator.
See [Write accessible documentation](https://developers.google.com/style/accessibility) for menu-path guidance.
