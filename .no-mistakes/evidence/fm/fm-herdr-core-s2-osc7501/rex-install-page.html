Installation

At the current stage of beta testing, the macOS application and the Linux and FreeBSD server are available to all testers.

We already have Rex servers running on Windows, and we have Rex clients for iOS, Linux, and Windows at varying stages of readiness. We hope to expand the scope of public testing quickly, but they aren’t part of testing yet.
