# Installation

**At the current stage of beta testing, the macOS application and the Linux
and FreeBSD server are available to all testers.**

We already have Rex servers running on Windows, and we have Rex clients for
iOS, Linux, and Windows at varying stages of readiness. We hope to expand the
scope of public testing quickly, but they aren't part of testing yet.


The macOS
client is fully self-contained with a local server that lets you get up
and running quickly. We plan on adding support for more platforms for the
client in the future.
