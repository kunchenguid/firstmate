# Backlog

Every piece of work still open when Juggernaut replaced the two repositories it grew from.
Both repositories stay where they are and keep their own history; nothing here is closed, moved, deleted or started by being listed.
This is the card index, not the books moving.

The two sources are preserved for what they can no longer show in public: the retired add-ons repository turned private, so its branches and its pull request are recorded here with their links and their head commits.
Anyone with access to that repository still sees every branch and commit; nobody else does.
A recorded branch with no commits ahead of the retired main holds nothing that main did not already have.

## How to read a row

- **Item** is the durable id the work has always had, so it can be found in history, in a task record, or in a conversation.
- **Type** says what kind of work it is, and its priority, where one was set.
- **The ask, or the finding** is why the item exists: the owner's own words when he set the work, or the defect a review found.
- **State** is the item's standing today: in flight, queued, held on something outside it, or blocked for the owner's call.
- **Link** is the branch, the head commit or the pull request, or a dash when the work has no ref of its own yet.

An item held on an outside condition does not start until that condition clears.
A blocked item waits for the owner: only he can make that call.

Nothing here starts early: each stage begins only when the owner says so, and the stages before it are finished.
The rename is the exception only because it is already under way; it is listed where it sits in his order.

   State: landed.
2. **This card.** Every open item, every unlanded branch and every open pull request from the two repositories, recorded in one place.
   State: this change.
3. **The product is Juggernaut.** Rename the product surfaces so a user never reads the old name: user-visible text, then the internal command, path and variable names behind it.
   State: user-facing text landed; the internal names, and the done gate that measures them, are still open.
4. **The agent CLI is `juggernaut-axi`.**
   State: not started.
5. **The tagline is "Ship like it's a game."**
   State: not started.

   No Call of Duty names, characters or logos.
   State: not started.

   State: not started.
