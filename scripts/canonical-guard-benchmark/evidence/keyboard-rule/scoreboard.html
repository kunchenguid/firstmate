1 · What the change is for

Keyboard shortcuts in the 3D editor must go through one place.

When a shortcut skips the middle box, the editor cannot switch it off while a drag is in flight, and nothing removes it when the panel closes.

2 · What the check says when it catches one

It names the file, the line, and the one line that fixes it.

$ git push packages/frontend/src/features/3d-viz-v2/api/hooks/use-evasion-concat-key.ts:8 [keyboard-listener] raw window.keydown listener is outside the engine boundary. The engine owns scene keyboard gating and listener teardown, so feature listeners must use its adapter. Replace with: useSceneElementEventListener(target, type, listener, opts)
➤
What replaces it
useSceneElementEventListener(window, 'keydown', onKeyDown)

One import. The editor gets the shortcut, and the shortcut gets the editor's on/off switch and its cleanup for free.

Captured from the project's own command on case string-built-event-name.
